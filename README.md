# ServiConnect - Protótipo inicial

Protótipo estático feito com HTML, CSS e JavaScript. Não precisa de XAMPP, PHP ou MySQL.

## Como abrir

### Forma mais simples
1. Extraia a pasta.
2. Abra `index.html` no navegador.

### No VS Code
1. Abra a pasta `ServiConnect-Prototipo`.
2. Se a empresa permitir, instale a extensão Live Server.
3. Clique com o botão direito em `index.html` e escolha `Open with Live Server`.

## Funções demonstrativas
- Nome do produto editável e salvo em `localStorage`.
- Categorias e profissionais fictícios.
- Ordenação por preço, distância ou avaliação.
- Favoritos demonstrativos.
- Solicitação em três etapas.
- Cálculo de referência, faixa de ±20% e resumo.
- Dashboard de cliente.
- Estrutura inicial de PWA.

## Limitações
Não há autenticação, banco real, pagamento, Google Maps, ViaCEP, chat entre pessoas ou envio de documentos. Use somente dados fictícios.
